## Plate Detector model

The Plate detector model was created and prepared specifically
for this project.

Dataset:
[https://huggingface.co/datasets/aniketbehera/hsrp-classification-dataset](https://app.roboflow.com/smarthsrp/license-plate-recognition-rxg4e-xyod6/2)

The dataset is versioned and documented separately on Hugging Face.

The HSRP classification model trained using this dataset is available
at:

[https://huggingface.co/aniketbehera/hsrp-classifier](https://github.com/Guardian-22/License_Plate_Detection_Yolov10s)
